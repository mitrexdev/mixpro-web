# Public website theme direction

Use the repository DESIGN.md and the owner's supplied ElevenLabs editorial reference. Keep photography central, Inter for the approved font substitute, display weights at 300, body at 400/500, restrained pill actions, soft corners and hairline dividers. Atmospheric pastel gradients remain decorative, never action fills or text colors.

## Dark mapping

The supplied reference primarily specifies light surfaces and includes dark surface tokens. The following dark mapping applies those tokens to the public site:

| Role | Value |
|---|---|
| Canvas | #0c0a09 |
| Elevated surface | #1c1917 |
| Strong surface / primary action | #292524 |
| Active action | #44403c |
| Display text | #fafaf9 |
| Body | #d6d3d1 |
| Muted | #a8a29e |
| Divider | #3a3531 |
| Strong divider | #57534e |

Dark CTAs stay warm near-black with white labels and subtle outlines. Navbar height is 64px. Theme selection remains available via the sun/moon icon, with browser persistence and system preference as the initial default. The user's earlier Inter substitution remains in place; this change does not introduce a licensed font download.

## Compact height update

The owner clarified that widths should remain unchanged. Restore the 1200px content cap. Homepage banners use a shorter 2:1 display frame with the complete image contained; discovery poster cards use 3:4 display frames instead of 2:3. Series detail posters keep their original portrait shape. Mobile banner copy spacing is reduced.
